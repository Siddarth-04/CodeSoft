# Coca-Cola Landing Page

This repository contains the **Coca-Cola Landing Page** project, built using **HTML, CSS, and JavaScript**. It showcases various sections like drinks, stores, franchise information, and a contact form, all presented with a modern and responsive design.

## Table of Contents
- [Features](#features)
- [Technologies Used](#technologies-used)
- [Screenshots](#screenshots)
- [How to Use](#how-to-use)
- [Icons Used](#icons-used)
- [Contact](#contact)

## Features

- **Responsive Navbar**: Includes navigation links, logo, and Font Awesome icons for the menu and search.
- **Dynamic Content Sections**:
    - Drinks section showcasing Coca-Cola products.
    - Store locator with global store locations.
    - Franchise section inviting users to join the Coca-Cola family.
    - Contact section with social media links and a message form.
- **Font Awesome Icons**: Used for various icons (menu, search, social media, and more).
- **Responsive Design**: Works seamlessly across desktop and mobile devices.

## Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
- **Font Awesome** for icons

## How to Use

1. Clone the repository to your local machine:
    ```bash
    git clone https://github.com/your-username/coca-cola-landing-page.git
    ```

2. Open the `index.html` file in any web browser to view the page.

3. Customize the content and styling as per your needs.
